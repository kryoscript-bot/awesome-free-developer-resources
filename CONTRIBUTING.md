# Contributing to Awesome Free Developer Resources

Thank you for your interest in contributing! We welcome all contributions that help make this resource better for developers worldwide.

## How to Contribute

### Option 1: Add a New Resource (Easiest)
1. Fork this repository
2. Open `README.md` and find the appropriate category
3. Add your resource with the format:
   ```
   * 🎨 **Resource Name** - Brief description of what it does and why it's awesome.
   ```
4. Commit your changes with a clear message
5. Submit a Pull Request

### Option 2: Report an Issue
- Found a broken link? Let us know!
- Think a resource should be removed? Open an issue with details.
- Have a suggestion for a new category? We'd love to hear it!

## Guidelines for Adding Resources

✅ **Do:**
- Only add 100% free resources
- Include a brief, honest description
- Ensure links are working and current
- Add relevant emoji to match the category
- Keep descriptions concise (one sentence)

❌ **Don't:**
- Add paid services or freemium tools with limited free tiers
- Include broken or outdated links
- Duplicate resources already in the list
- Change the structure or format significantly

## Categories Explained

- **🌐 Free Hosting & Cloud** - Deployment platforms and cloud services
- **🎨 Design & Icons** - Graphics, fonts, and UI resources
- **🤖 Free AI Tools for Devs** - AI-powered development tools
- **🔌 Free APIs** - Mock and live data APIs
- **🎓 Free Coding Courses** - Learning platforms and tutorials
- **🎮 Free Game Development** - Engines, tools, and assets

## Pull Request Process

1. Fork and clone the repository
2. Create a descriptive branch name (`git checkout -b add-new-resource`)
3. Make your changes
4. Test that all links work
5. Commit with a clear message
6. Push to your fork
7. Open a Pull Request with details about your changes

## Questions?

Feel free to open an issue if you have any questions. We're here to help!
